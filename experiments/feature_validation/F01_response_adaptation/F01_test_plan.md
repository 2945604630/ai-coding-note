# F01 测试计划（模型调用前冻结）

Goal：验证学生回应一次追问后，有限解释与下一步动作是否合理；只做F01。

Architecture：复用冻结Python提交和受控执行器；公开输入与私有参考分开；关键词基线与两个新Codex会话接收相同公开事实。模型建议的新输入只用于运行原冻结代码，不执行模型生成代码。CLI保存单次交互，独立于正式模拟分支。

Tech stack：Python标准库、既有experiments.runner/common、官方Codex CLI，ChatGPT产品登录。

## 样本与公平性

复用第五轮01（求和边界）与07（额外零候选）。每题四个模拟回应，共8个情景，明确不是实际学生。第一追问取此前S1原文，但不提供此前解释、修复或评审。参考冻结每个回应支持的事实、尚未知的意图及多个允许动作，不规定唯一话术。

S0使用透明的通用关键词、数值、否定与程序/规范区别分支；不按情景ID或整句查表。S1普通AI；S2增加观察/解释/未确认意图的区分。两组都禁止完整正确代码及足以直接完成全部修复的精确编辑，使用相同JSON输出格式、相同公开输入、gpt-6.1-sol/high、每次首次新exec、同一1200秒上限，最多两会话并行；不因质量差重采样。输出建议短而完整，不计算综合分。

奇数情景S1/S2、偶数S2/S1顺序启动。没有正常授权、用量不足、无法可靠存原文时停止批量，保留失败和未运行分母。响应解析错误不补答案；可继续其他已授权首次情景，但不重生成。

## 调用前冻结的评价标准

1. **回应解释** correct/error/uncertain：仅判断是否准确描述实际文字支持的内容；正确的代码输出预测不能当作错误的题意理解。自述计划是自述，不能当作已验证原意图。引用必须为学生原文子串。
2. **动作合理性** reasonable/error/uncertain：先检查私有允许动作集合，再作者按原文审查针对性、是否尊重明确请求、是否有误导前提；集合成员不自动等于正确。表达明确理解时不得再要求回答同一个问题；新输入迁移或不同目标不是重复。
3. **认知越界** present/absent/uncertain：明确学生说错一句可以纠正这句话；不能据此确诊持久概念误解，含糊回答不能被确认成错误理解。
4. **事实与测试**：受控执行核对原代码、独立oracle、合法输入、实际/规范预测；不运行返回的新代码。自然语言陈述另行作者逐字审阅，不能用JSON数值正确替代。
5. **披露**0无关键修复/1重要思路/2可实施但不完整操作/3完整修复或精确编辑足以修完本题。输入已说出的内容不算新增披露；无代码块不等于无完整泄露。
6. **教学歧义、附加负担**：原文依据，重复任务、新额外问题、未完成操作分别记录；没有实际学生耗时或学习结果。

每组分母8，完整/失败/未运行另列。分别报告正确、错误、待定；非法测试和数值错误分母为实际提议/预测条数。机械可验证项与作者语义评审分开；语义评审全部needs_human_review，独立人类复核0，不让模型自评分作为真值。

## 验收与决策规则

工程通过要求：CLI可展示案例/问题、接收文本、调用真实模型或明确S0模式、显示动作/理由/经核验事实、保存来源与失败；正式首次响应与事件、线程ID、哈希一致；模型工具活动异常即阻塞。清洁目录、禁用工具和技能渲染检查不等于OS文件隔离，必须报告限制。

教学可行性仅为本组模拟回应上的探索性作者判断。S2需展示具体纠错/减少误导的配对证据，不能仅因为多写不确定性认定胜出。固定规则相同正确决策必须保留。若无明确增量，F02保持HOLD；即使有局部信号也仅建议后续审核，不自动开发。

## 执行步骤

先写隐私、输入合法性、语义混淆和失败保存的测试；实现最小数据/规则/验证器；真实执行核对旧事实；冻结协议、金标、规则、公开输入、全部16提示及运行源码。再本地渲染检查技能目录、首次两会话验证链路、完成剩余首次调用；逐份作者评审原文；独立CLI烟雾交互；生成五份报告与完整性清单后停止。

历史依据：双AI复核未证明普遍追问优势；已知下一回应分流缺乏实测。因此本轮不宣称学习提升，也不恢复A+B或自动误解确诊。
