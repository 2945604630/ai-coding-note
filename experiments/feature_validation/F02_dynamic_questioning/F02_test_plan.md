# F02 冻结测试方案 v1

只验证连续追问，不开发下一功能。三个已核验程序：循环边界、多缺陷、边界补偿与偏移。每例四条模拟路径，共12条；正确、错误、部分理解与意外回应。模拟输入不代表真实学习者。

每例共享一次真实S1第一问，随后每条路径最多两次学生回应、三次教师输出；理解充分可提前停止。共享第一问只计3个独立首问，不重复计12次。预算耗尽与教学上适时结束分别记录。

主比较：每次S1决策时，S0读取完全相同的公开输入和实际历史，作为单步配对对照；S0回答不进入S1历史。另跑S0自身完整路径，记录步骤和不适配，不能把不同历史的路径差异直接称为等输入增量。

S0规则依据源码AST、明确的学生表达和历史已答主题，使用固定追问库。先冻结规则，再冻结回答库；规则不访问路径ID、参考原因或允许动作。禁止事后适配。

学生回答库含两轮预先写定原文，以及合法n=0..8的数字变体。变体只用于接住实际问题的输入，属于同一路径，不是额外样本。选择器只能按问题主题、版本和输入选择现有字节；未覆盖的问题、多个未支持输入或未知版本记path_incompatible，不补写回答。意外回应可明确打断问题，但不能称其已经回答了原问。

普通S1共同边界：不代做完整修复、不长期知识确诊、不捏造执行、不重复已解决内容；当前理解充分可自主修改。无S2。每轮全新官方CLI会话，显式传入同路径实际历史，不resume；同模型gpt-6.1-sol/high、首份输出、并发最多2、正常产品登录。工具/联网/本地技能关闭；无操作系统读隔离保证，审计全部工具活动。

客观事实：独立oracle与原受控执行器，只运行冻结原码及已审核local_patch；任何模型新源码不执行。版本、合法输入、预测、引用和原始输出hash可机器核查，不能因此认证教学质量。

冻结量表：每个教师决策分别评首问/后问区分力、上一轮信息利用、动作合理性、重复、无依据知识推断、程序事实错误、完整修复泄露、结束是否适时。正向项标签reasonable/error/pending/unscorable；风险项absent/present/pending/unscorable，N/A不纳入分母。逐项原文与依据，保留分母；路径不适配的下游轮次不伪造分数。

区分力要求：问题能核对程序行为与契约、区分明确竞争解释，或识别剩余未解决缺陷；仅不同措辞、冗长条件分支不加分。利用新信息要求：承认已回答的主题并改变实质目标或允许停止，不重复整套问题。明确理解后仍原样追问为失败；新版未知时请求材料或暂停合理。单个局部测试成功不证明全修好。

作者逐项审查为模型辅助初审，全部needs_human_review。预选C01错误路径、C02正确路径、C03意外路径做3个独立同模型辅助审查，不共享作者分数；相关错误风险、非人类认证。不因审查不理想重采样。无真实学生时不报告学习效果。

停止：调用受限/权限失败保留首份失败，停止新增调用；不mock、不重采样。完成报告后停止F02，不进入F03或完整工作台。
