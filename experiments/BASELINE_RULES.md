# 实现细则：首次 A/C 比较之前固定

A0：只在原题正确提交或 `self_rating >= 4` 时产生积极标记，不表达新题独立观测，也不表达认知假设。A1：程序原因到概念的固定映射形成待训练标签；每次提示、精确修改或答案查看计 1 次提示，正确提交得 `100 - 3*提示次数` 分，达到 80 更新该标签技能。A1 不检查审核、外部辅助、概念匹配或题族暴露；推荐不会随撤回更正。本地简化规则不得冒称上游具体实现或 UI 行为。

A0 没有误解确认层，其该项 0 表示不适用；A1 的误解指标实际指固定错误标签被当作待训练缺口的误用。A2 只保存本次合格表现，不产生长期 mastered。正常原题独立表现和新题独立表现分别统计，辅助、未知、无效审核不会获得积极独立观测。脚本里外部辅助为 none 仅是夹具假定，不能验证真实学习者没有作弊。

C1 由通用 AST 变异产生候选，witness 只用候选参考提供期望；合法 witness 上参考自身异常拒绝，不查独立 oracle。对 witness 非等价变异，至少一个当前测试观测到差别算检出；全部检出才接受，有限等价性不作全域证明。C2 的参考与已有测试都同独立 oracle 比较；审题 approved_fixture、概念匹配、目标变体在合法 witness 上非等价且被当前测试检出才接受。C2_without_target 除去最后的目标闸门，其余规则完全相同。

所有基线使用相同已冻结事实或题包；规则预算及额外执行各自记录。C2 不额外暗藏通用变异测试，避免混淆目标收益。审核记录是预置作者判断，审核耗时不记为零：真实人工审核尚未运行，成本未知。
