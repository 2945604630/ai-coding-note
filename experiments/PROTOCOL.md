# 第三轮机制实验：冻结协议 v1

日期：2026-10-08。用户已授权最小实验代码与 B→A→C 实际运行；不开发产品、不改第一二轮文档、不使用比赛截止时间评分。

## 范围与执行计划

使用 Python 3.12 标准库，三个独立入口 `python -m experiments.run_b`、`run_a`、`run_c`；共享受控运行器和自拟参考题。实验结果写入 `experiments/results/<run_id>/`，不覆盖历史运行。

- [ ] 冻结 `data/b_cases.json`、`b_claims.json`、`a_traces.json`、`c_packs.json` 和本协议的 SHA-256；评估前检查完整性，标签仅供评分，不进入核验器。
- [ ] B：先写核验器／运行器反例测试并记录失败，再实现、测试、运行 15 个程序案例的固定输出对照。
- [ ] A：先写独立资格与撤回测试，再实现、测试、运行 12 条事件轨迹。
- [ ] C：先写弱测试／共同错误／偏题测试，再实现、测试、独立运行 14 个题包。
- [ ] 比较原始计数、失败、额外运行和操作成本，写五份报告；停止开发等待审核。

这些勾选代表冻结时计划；完成状态记录在 results 和最终报告，冻结后不修改协议。

## B 判定规则

四类受限缺陷：极值初值、inclusive sum 循环端点、累加覆盖、索引循环多一步。15 个程序覆盖正确、不同原因相同输出、多错误、证据过期／不存在、非法区分输入、事实预测相符但因果无依据、观察不足。

固定诊断输出由本助手编写，是故障注入输入，绝非真实 Provider 输出。B0 接受给定诊断；B1 仅检查结构、证据 ID、代码版本和已有真实失败；B2 在同一输出上额外执行合法预测及受限 AST 单缺陷干预。有效预测不是因果成立：还须存在对应局部机制、干预减少已观察错误且不破坏原通过用例。无法核验自然语言／人的理解保持待定。支持只限本程序、选定用例与局部干预。

核验器不得读取 `gold_causes`、`forbidden_conclusions` 或案例 ID 查表得出原因。评分在核验完成后对照预设标签。标签由本助手源码审阅和自拟参考确定，尚无外部人类独立复核；不把它称真实学生认知真值。

B0/B1 是成熟思路的本地规则近似，不是运行 SmartCode／Iris 原系统。三组事实输入和固定输出完全相同；额外执行次数与延迟单独报告。指标：正确原因／错误归因／正确程序误报、有效覆盖、拒绝与待定、坏引用、有效反证、额外执行。零输出不能认定机制成功。

## A 判定规则

A0 是自评高分或原题 AC 产生积极掌握标记的简化规则；A1 是固定概念映射、提示扣分后的积极技能更新；均非上游完整复现。跨规则比较的是“不合格事件产生积极掌握更新的次数”，不能反向声称上游在 UI 中宣告独立掌握。

A2 保留程序原因、认知假设、表现三层；错误程序不能确认人的误解。有效诊断问题的错误回答只支持限定误解；未确认不确定性训练不得自动激活。AI 精确修改与提示、答案暴露、外部辅助未知、未审核／错概念题、环境失败不形成独立新题观测。答案暴露按题族持久记录；撤回诊断撤销其派生推荐，保留历史事件。

12 条轨迹是脚本事件，不是真实学生；状态规则成功不能证明迁移或长期掌握。正常有效首次新题通过必须保留，不能全部拒绝。

## C 判定规则

14 个题包包括四类目标题、弱用例、参考／测试共同错误、偏题、缺审核和坏参考。C0 格式、参考通过现有测试、starter 失败且实际运行。C1 加入通用 AST 变异：比较边界、常数、二元运算、range 端点、累加替换及下标表达式替换。不能故意删掉目标变异制造 C2 优势。

通用变异在冻结 witness 输入上与候选参考有行为差别者才进入计数，等价性仅指本 witness 集，不是全域证明；环境／资源异常的变异单列，合法输入上程序自身的 IndexError 等算可检出的错误行为。C1 要求所有此类变异被当前测试检出；这是严格的有限通用变异基线，需报告误拒和成本。

C2 基础检查＋独立预设参考＋指定目标错误变体检出＋题意目标审核记录；额外运行 `C2_without_target` 消融，区分收益来自目标检查、独立参考或预设审题。审题记录和目标标签是作者提供的固定评审夹具，不是已经完成教师用户研究。必要记录缺失时 hold。

目标检出率与题包接受分开。人工构造题包的结果只证明闸门在这些夹具的行为，不能替代真实 AI 出题质量；缺 Provider 时真实生成实验 not_run。不给模型自审充当真值。

## 执行边界与资源

只执行已审阅的自拟单函数源码及本地确定性 AST 变异，绝不执行模型生成的任意源码。输入仅短整数／整数列表；AST 禁止 import、文件、网络、动态调用和反射。每次隔离 Python `-I -S` 子进程，Windows Job Object 限制进程数、提交内存，父进程设超时；JSON 输出限长。措施未经攻击审计，不称通用安全沙箱。

Job Object 依据 [Microsoft 的扩展限制结构](https://learn.microsoft.com/en-us/windows/win32/api/winnt/ns-winnt-jobobject_extended_limit_information)和[基础限制标志](https://learn.microsoft.com/en-us/windows/win32/api/winnt/ns-winnt-jobobject_basic_limit_information)。
