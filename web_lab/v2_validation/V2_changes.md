## 打开与启动

当前服务：**http://127.0.0.1:8006/**，实验管理：**http://127.0.0.1:8006/manage**。

双击项目根目录 `start_web.bat`，或在项目目录运行：

```powershell
python -X utf8 -m web_lab.launch --port 8006 --data-dir data/aic_demo
```

沿用 `data/aic_demo/aic_web.sqlite3`，没有重建数据库。8000 上的原服务未停止，其数据库保留独立。原网页源码和 SQLite 快照在 `preserved_20261011T085720Z/`。

## 改动

- 默认主页直接选题，提供继续学习、最近记录与活动次数。自动测试记录放在实验管理，活动次数不表示掌握程度。
- 学习页采用约 43% 代码、57% 对话布局。代码直接编辑，支持缩进、保存新版本、版本选择、源码差异与版本对应证据。未保存草稿暂存在当前浏览器。
- AI 与学生使用连续聊天气泡；固定首次引导明确标注。快捷提示真实提交到原教学接口；编辑与查看证据操作追加事件。停止后收起输入框，转入修改、新题或继续学习。
- 回答先保存，再使用原异步模型队列。等待时间、连接状态、刷新恢复、失败原因、明确重试及原始结果保留；没有伪造流式动画。
- 新题通过独立页面进入，原首次冻结、帮助记录与后续修改接口继续使用。原 S0/S1、评价、事件、工件及 JSON/CSV 导出在实验管理保留。
- 每次回答、代码、帮助、反馈与界面操作分别记录来源。旧输入来源缺失保留未知；创建设定与实际输入来源分开统计。更正通过追加事件处理，不修改原模型输入或输出。

这是工程烟雾测试与故障注入，不是真实学生数据，也不评判教学准确率。故障注入仅产生空原文与连接失败，保存在独立 `failure_fixture_data/`，未填充成功 AI 回答。

浏览器首次烟雾测试因 CLI 隐藏 `navigator.webdriver`，来源误记为手动声明；该断言失败已保留。修复为显式自动化标记跨页面传递，并追加创建设定、回答和核验来源更正。原输入、调用元数据及程序证据未改写；旧空准备会话也追加了已知自动化来源说明。更正后的逐回答统计为两条自动测试输入，不能计为真人。
