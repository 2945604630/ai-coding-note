# AIC 网页交互实验台 V1

用户给定的十二部分需求为本轮已授权规格，直接开发与启动，无额外设计批准流程。

采用环境已有 FastAPI / Uvicorn，原生 HTML、CSS、JavaScript，SQLite WAL。仅 127.0.0.1:8000。
F01 复用冻结 core 的题目、首问、S0、提示词、守卫和 phase2 官方传输；F02 复用 core、baseline、runtime.trial_cli.generate 及 cli_guard v3。不改冻结文件，不写旧数据目录。

网页仅四个页面：首页、三栏交互、历史、统计。F01 一次回应；F02 最多三次教师输出（含初问），按原协议提前结束。新源码独立记为未验证文本，仅在模型上下文作为不可信材料，不替换 executor 的审核源码。

SQLite 实验、轮次、调用尝试、评价修订、源码版本、事件、备注分表。先提交回答及输入快照，再排队后台调用；单个实验只允许一个未完成调用。重试新增 attempt，不覆盖第一次。重启后未完成调用记为失败，用户明确重试。暂停或结束不丢弃已经提交的调用结果。

模型传输成功、守卫放行、用户评价分别计数；所有教学语义未人工认证。来源 real_user / automated_test 分开筛选。JSON 包含全部元数据、历次评价和允许的执行工件（原始字节 base64）；CSV 带 UTF-8 BOM，公式样式文本转义。历史不迁移，网页只列 V1 自身数据库。

验收用临时库及明确模拟服务覆盖异步、幂等、失败、重试、重启、版本和导出，再有限真实 Codex F01 单轮及 F02 连续调用；浏览器检查四页与主要控件。真实调用出错保留日志，不合成为成功。
