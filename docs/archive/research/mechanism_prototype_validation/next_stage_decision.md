# 下一阶段决策：先证伪成本必要性，再确定产品

日期：2026-10-08。Python 3.12.10／Windows，本轮仅实现机制实验。真实模型实验 `not_run`，未检测到当前进程的 Provider 环境配置；实际 API 调用、token 和费用均为 0。没有访问私有凭据，也没有生成参赛产品、UI、Fork 或部署。

**现在不进入完整参赛产品。A/B 有条件继续，C 的独立创新题工厂暂不立项。** 结构 IV 从优先完整产品降为待验证组合；下一轮只建议一个有限诊断对照交互原型，检验追加执行是否比 AST 规则值得使用。

## 1. 明确判定

| 方向 | 决定 | 支持的范围 | 不可据此主张 |
| --- | --- | --- | --- |
| A | CONDITIONAL GO | 分层、资格和撤回规则成立；合格4个全保留、不合格更新0 | 真认知诊断、学习提升或比人工选概念更好 |
| B | CONDITIONAL GO | 局部干预与事实反证可复放；B1错误原因4→0 | 胜过 AST 简单对照或真实 AI 诊断可靠性提升 |
| C | NO-GO（独立创新题工厂） | 离线质量工具能识别共错和审核缺失，独立入口有效 | 目标检查优于通用变异，自动审题或教师成本下降 |
| 结构 IV | 不优先开发完整产品；保留候选 | 固定题包、最小 B/A 组件可以日后联接 | 组合端到端已验证、先前设计评分仍代表实测排名 |

工程模块能运行与产品值得立项是不同判定。C 的 NO-GO 不等于检查程序没有用；A/B 的 CONDITIONAL GO 也不等于已经获得竞赛创新认可。尚无样本支持无条件产品 GO。

## 2. B 和 C 能否独立成品

B 的模块独立性已由单独 CLI 展示：无需 CodeHelper、学习者数据库或 C，即可输入固定 JSON、执行并导出证据。具备发展成有限诊断复核／助教回放工具的技术基础。但当前 AST 对照在原因筛选上同样无误且覆盖更高，追加运行、可信标签和用户信任收益仍需证明；不宜直接命名为普适高可信错因诊断产品。

C 同样技术独立，14 个题包单独完成质量检查，没有因为它不是首选而少做实验。作为已有题库的审计工具可留用。当前把目标变异当核心创新不足：四个弱题都被通用变异抓住，新增三个拒绝来自独立参考／预置审核。除非真实教师提出独立需要、目标检查显著省工且不损质量，否则不作为另一条产品主线。

## 3. CodeHelper 的底座判断

目前不值得先做整仓 Fork。B/A/C 核心已用 Python 标准库独立运行，无需 Electron、原生 SQLite 或 CodeHelper 的旧掌握逻辑。CodeHelper 的编辑器、错题入口和桌面执行可在确定桌面／多语言需求后复用，但它不会自动带来三层事实或机制增量。

本轮没有安装 CodeHelper 基线，也没有比较 Pyodide。因此不能据 Python CLI 的成功宣称任一底座更稳定。未来宿主选择必须先比较同样的输入输出事实、取消／异常分类、版本回放和接入改动；以 adapter 接独立核心优先于修改多个共享全局状态。

## 4. 下一轮仅一个小型交互原型

**有限诊断对照与证据回放原型。** 只使用已审核 Python 小函数和固定题包，让评审者看到题意、实际输入输出、固定或真实 Provider 的候选原因，在 B_syntax 与 B2 间比较：接受／待定、证据充分程度、漏掉的真实原因、耗时与一次核验操作。保留一个“我认为还不足以确认”的反馈及手动概念选择，显示本次辅助标记，不做自动课程与长期掌握。

原型目的：判断用户是否需要执行证据而愿意承担额外成本，以及简单 AST 判断遇到真实代码时是否确有误归因。若只是更好看、更多 JSON 或更少输出，停止把 B2 当独立创新点。A 只复用必要的暴露／撤回审计，不先铺完整认知层。本轮未开发该原型，须待用户审核报告后再决定。

## 5. 下一轮必须补的证据与退出条件

| 缺口 | 下一项最小测试（尚未运行） | 应改变决策的结果 |
| --- | --- | --- |
| B 的自然诊断增量 | 同一 Provider/参数/事实冻结预算；加入 B_syntax 对照和无模型规则；保留所有原始输出 | 追加执行仍无准确、覆盖或用户证据收益→采用简单规则/改选题 |
| 标签独立性 | 两名能读代码的评审分别标原因与允许待定范围，复核本轮标签和多缺陷案例 | 人也无法可靠标因果→收缩主张为可证伪行为，不自动确因 |
| B 的困难反例 | 至少包含 AST 匹配但原因不成立、补偿修复、混合缺陷、别名/重排/模板外代码；预先冻结 | B2只能靠扩大模板，不优于存在检查→没有关键增量 |
| A 的必要性 | 与手动选概念＋辅助/题族资格勾选对照，小量评审者完成流程并记录步骤与耗时 | 状态无误但额外操作不值→删自动误解确认，保留简单审计 |
| C 的独立价值 | 少量真实生成题、独立专家审题；对照通用变异＋同样oracle/审核；测总审核修复时间 | 仍无额外检出或省工→只留后台质量工具 |
| 底座和端到端 | 只在底座被选后做一个最小 adapter；同版本事件与输出可重放，故障不写入学习失败 | 稳定事实难以取得→先修执行协议，不扩UI |
| 学习效果 | 未来另行设计未见题效度、首次独立作答和延迟保持研究 | 本轮没有数据；不承诺学习提升 |

这些是未来测试建议，不是已授权开展的追加产品工作；样本量和门槛需在那轮开始前固定。不以比赛截止日期调整判断，也不用本轮小样本宣称统计上的普遍提升。
