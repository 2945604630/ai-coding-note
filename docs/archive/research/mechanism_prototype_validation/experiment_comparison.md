# 三组机制实验比较：能运行与值得产品化分别判断

日期：2026-10-08。Python 3.12.10／Windows，本轮仅实现机制实验。真实模型实验 `not_run`，未检测到当前进程的 Provider 环境配置；实际 API 调用、token 和费用均为 0。没有访问私有凭据，也没有生成参赛产品、UI、Fork 或部署。

**本轮支持有限工程可实现性，没有证明任何方案具有充分的产品创新或学习效果优势。** 相对规定的简单基线，B/C 有差异；加入更简单 AST 对照、强通用变异和消融后，最关键的创新归因需要收缩。A 的审计规则最清楚，但用户价值未测。

原始冻结 v1/v2 均保留；b09 先修遗漏首元素，后修题面／未知前提矛盾，公开两次修订和所有结果。B_syntax 明确事后探索，不作为未注册的主比较。C starter 误拒未修数据。MemoryError 分类修正后重跑；B 的混合资源证据资格也已修正并回归，最后复跑计数一致，耗时波动保留。

## 2. 实现成本与复用边界

| 模块 | 现有最小实现 | 本轮运行成本 | 下一步主要维护成本 |
| --- | --- | --- | --- |
| 共同运行器 | stdlib、AST 审核、Windows Job、独立 Python 进程 | 128MiB、进程 1、默认 1.5s；资源异常分开 | 异常分类、Windows兼容；仅支持固定可信函数 |
| B2 | 四类局部干预＋probe＋证据版本 | 79 次函数／43 批；核验 1704.404ms | 语法变化、补偿性干预、多缺陷、候选因果可判定性 |
| B_syntax 事后 | 相同机制存在性与输入检查 | 31 次共享事实／15 批，追加执行0；规则 5.941ms | 同样受四类模板覆盖限制；不提供行为证据 |
| A2 | 事件回放、三个状态层、依赖推荐撤回 | 36 事件 1.024ms；无模型调用 | 审题和题族效度、辅助事实来源、持久化、用户操作 |
| C1 | 通用变异与 witness 行为比较 | 343 次／89 批 | 有限等价判定、测试成本和未检出变体 |
| C2 | 独立规范 oracle、目标变体、审核资格 | 158 次／46 批；审核人工时间未知 | 每个新题意建立独立参考、真实概念审核，避免共错 |

这些是本机顺序执行时间，不能折算教师总成本或产品性能。复用了方法，没有移植大型上游。共享输入规范、版本、真实 runner、序列化；B 的程序原因核验、A 的理解确认、C 的题包批准分别保留自己的判定，不能用一个“可信/掌握”布尔值串通全部环节。

## 3. 哪些组合有必要，哪些还没有证据

任何 UI 若显示诊断，应保留原始事实、版本、支持范围和待定状态；若显示独立表现，必须保留辅助与题族暴露资格。训练推荐若由诊断派生，应能撤回。这些关系由本轮反例直接支持。

C 的独立参考和审题可用于固定题包；无需在线生成。B 不依赖 A 才能复放；A 可采用人工选概念，尚未证明必须由 B 自动确认。当前无证据要求完整知识图谱、BKT、FSRS、动态 Socratic、多 Agent、SQL、自动补丁闭环或全量题工厂。

结构 IV 仍是日后可组合的容器，但第三轮不能维持“已有实验优势的优先完整产品”定位。先前 83 等数字只是设计潜力评分，不用这些分覆盖现在的反例。若未来 B 不胜 AST、A 不胜人工简单流程、C 仍只复现成熟质量检查，应调整选题，不应继续加功能包装。
