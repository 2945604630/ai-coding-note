# AIC Web V1 Implementation Plan

> 本轮按用户已批准的完整需求在当前会话逐项执行，不引入多 Agent，不等待额外批准。

**Goal:** 本地网页选择冻结案例，与真实 Codex 交互，持久化并导出完整实验。
**Architecture:** FastAPI 同源 API + 原生四页界面；独立 SQLite 和工件目录；薄适配原 F01/F02。
**Tech Stack:** Python 3.12、FastAPI 0.118.3、Uvicorn 0.49.0、SQLite、unittest。

- [x] 1. 先建立 `web_lab/tests/test_api.py` 的流程测试。命令 `python -X utf8 -m unittest web_lab.tests.test_api -v`，初始因缺少 app 失败。
- [x] 2. `web_lab/teaching.py` 只桥接冻结案例、提示、规则、原传输及 v3 守卫；保存模块版本哈希。
- [x] 3. `web_lab/store.py` 建立实验 / 轮次 / attempts / feedback / versions / events / notes 表；原子提交、幂等、重启记失败、评价追加。
- [x] 4. `web_lab/service.py` 在线程池调用；每次先固化快照，失败原文与日志留存；重试新目录；暂停/结束保留结果。
- [x] 5. `web_lab/app.py` 接口输入校验、同源与本地主机保护、工件白名单、JSON/CSV 导出。统计分来源保留分母与空值。
- [x] 6. `web_lab/static/{index.html,style.css,app.js}` 完成中文四页、可恢复轮询、三栏聊天、人工评价、未验证源码记录、历史筛选、统计与导出。
- [x] 7. `start_web.bat` / `web_lab/launch.py` / `web_lab/__main__.py` 默认本地启动并打开浏览器；单实例；依赖缺失仅按 requirements 安装。
- [x] 8. `web_lab/backup.py` 使用 SQLite backup API；保留工件；README、字段说明和测试报告。
- [x] 9. 运行新接口测试和原 F01/F02 回归；真浏览器检查；有限真实 Codex 验收，来源自动测试。
