# A：简单练习流程与复杂诊断流程

日期：2026-10-09。真实学习者 0；真实 AI 假设生成 blocked。已完成确定性配对回放、固定题目程序检查及最小 CLI 演示。以下推荐准确率属于作者脚本，独立成功属于带资格规则的脚本代码选择记录，都不是学生学习效果。

**结论：当前没有证据表明 A 必须自动确认误解。** 简单版已完成选择目标、训练、新题记录、辅助/暴露限制及撤回闭环；复杂版在十条脚本中没有提高总体目标判断，增加了追问和确认步骤。复杂流程可帮助某个选错目标的场景，也会因无效追问产生错误推荐，不能用状态机通过测试主张学习提升。

## 1. 两个公平工作流

| 环节 | A-simple | A-complex（当前规则演示） |
| --- | --- | --- |
| 目标来源 | 学生选择概念，允许不确定/暂不训练 | 固定程序错误证据后提出脚本候选；真实 AI 阶段 blocked |
| 澄清 | 不强制追问，可更正选择 | 1~2 个固定追问，支持限定候选或保持待定 |
| 确认 | 接受自选目标 | 暂时采用目标；待定回到同样手动选择 |
| 训练 | 同一个概念的同一固定题包 | 同左 |
| 新题 | 题面、函数和题族不同；记录首次代码选择结果 | 同左 |
| 审计 | 辅助、未知辅助、答案暴露、题目资格、失败和撤回 | 同左 |

两组均不将程序错误直接写成认知缺口，不因用户选择手动流程而删除独立验收或质量限制。单个错误追问回答最多记 `supported_by_single_probe`，`understanding_confirmed` 始终为 false。用户确认的是本次训练目标，不是系统已经证明其误解。追问辅助不明时保持待定。

新题参考答案在本次记录后才显示；暴露题族保存在会话历史里，即使新建会话也不会清除。验收辅助默认 unknown，暴露来源未知也不获得独立资格。可撤回推荐，但保留原推荐与失败，不重写历史。

冻结数据（仅本机证据：`experiments/round4/data/a_study.json`；不随 Git 分发） 共三个概念、六道题，两组内容完全相同：

| 概念 | 训练题 | 新题 |
| --- | --- | --- |
| 累加与覆盖 | 列表求和 | 元素平方和 |
| 循环端点 | 1..n 求和 | 构造 1..n 列表 |
| 索引边界 | 顺序复制列表 | 逆序复制列表 |

两道题有不同题面和参考函数，未靠更换 ID 冒充新题。固定参考与目标错误程序实测 36 次函数调用、12 个子进程：六个参考均通过各自三个输入；六个错误版本均被至少一个测试检出。详见 question_quality_raw.json（仅本机证据：`experiments/round4/results/A_scripted_20261008T155759536239Z_5d4f32/question_quality_raw.json`；不随 Git 分发）。

审核为作者题意检查和独立规范计算检查，教育专家审核 pending；不宣称教学效度已确认。新题是小型代码选择题，没有学生独立编写代码，不能等同于独立编程迁移能力。题目内部固定答案 ID 不向用户显示，CLI 对显示位置作可复现的重排，两组使用同一规则。

十条场景的“适当目标”是预先冻结的作者标签；假设与答案都是脚本，不读取标签来作流程决策。两组回放同一新题答案以检验资格规则，因此相同验收计数不能证明学习效果相同。脚本默认为给定有效追问作答；CLI 额外询问追问辅助，未知或受助则保持待定。

## 4. 复杂流程何时帮助，何时出错

| 场景 | 观察 | 可得结论 |
| --- | --- | --- |
| w01 | 自选目标与追问一致 | 复杂流程没有改变目标 |
| w02 | 自选错概念，追问支持正确的另一个目标 | 脚本里确有纠偏可能；真实频率未知 |
| w03 | 程序错误，但追问答对；选择暂不训练 | 不能从代码失败确认认知错误 |
| w04 | 候选错误，追问没有支持；回到正确自选 | 保持待定和手动入口有用 |
| w05 | 有噪声的错误追问支持不适当目标 | 复杂版首次推荐变差；错误回答不保证有效诊断 |
| w06 | 验收辅助未知 | 两组都不给独立成功资格 |
| w07 | 新题答案已暴露，要求重试 | 两组都保留暴露，不因重试获得资格 |
| w08 | 场景假定题目审核未通过 | 两组都不接受验收资格 |
| w09 | 首次都选错，撤回后手动更正 | 简单流程也能实现纠偏和审计 |
| w10 | 两候选，需两次追问，新题失败 | 多问没有消除新题失败；保持失败事实 |

w02 和 w05 一增一减的平衡是作者场景设计，不能估计学生总体中的净收益。“适当目标”也未经过真实学习者或教师效度检验。当前最强结论是复杂流程并非实现闭环的必要条件，误解确认价值仍待验证。

## 5. 可操作的最小试用原型

trial.py（仅本机证据：`experiments/round4/trial.py`；不随 Git 分发） 已能实际交互：选择目标或固定错误样例、接受/跳过追问、确认/更正目标、选择训练代码、声明辅助和暴露、完成新题、评价额外步骤。复杂组展示固定程序的实际输出及规范值，候选来源明确为规则而非 AI。仅运行冻结的代码选择项，不接受任意源码进入执行。

```powershell
$env:PYTHONIOENCODING='utf-8'
python -m experiments.round4.trial --workflow simple --actor agent_demo --participant reviewer_simple
python -m experiments.round4.trial --workflow complex --actor agent_demo --participant reviewer_complex
```

participant 为匿名本地标识；同一标识的已暴露题族会持久保留。支持 `learner_self_report` 标签供人工试用记录，但该标签只来自操作者自报，仍需研究者确认来源；本轮没有任何此类会话。不能用同一人重复相同新题进行跨组学习比较，暴露会使后一次失去独立资格。

两份带完整终端日志的演示为：

| 演示 | 实际菜单交互 | 机器驱动总时长 | 新题结果 | 来源 |
| --- | ---: | ---: | --- | --- |
| 简单流程 | 7 | 0.1141 秒 | 代码选择失败，已保留 | agent_demo |
| 复杂流程 | 11 | 0.1737 秒 | 代码选择失败，已保留 | agent_demo |

演示输入、执行结果、时长及接受度字段均保留。两次输入“可以接受”是助手脚本选择，**排除于人类接受度结论**。小于一秒的时长是管道驱动过程，不是学习者完成时间。自动测试会话也同样排除。

原始演示：simple session（仅本机证据：`experiments/round4/results/Trial_20261008T160402506710Z_893052/session.json`；不随 Git 分发）、complex session（仅本机证据：`experiments/round4/results/Trial_20261008T160402505711Z_c46384/session.json`；不随 Git 分发）；终端日志在 round4/results/demo_simple_01.log 和 demo_complex_01.log。失败结果没有删除或重跑成成功结果。

当前没有基于真实 AI 的 A-complex，也没有完成学生实验。后续若经审核开展真人研究，须先独立审题、确认目标标签，使用不相互暴露的配对题包并平衡顺序，记录人类时长、拒绝追问、错误推荐和新题表现。此处是证据缺口，不是已经开始招募或研究。

**A 本轮判定：简单版作为低复杂度试用候选；自动误解确认 HOLD。** 简单版实现了主要功能闭环，但“大部分用户价值”与学习收益尚不能量化或确认。不要为保留复杂版而加入更多追问、题库或认知模型。
