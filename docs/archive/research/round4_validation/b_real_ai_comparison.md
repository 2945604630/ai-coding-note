# B：执行核验与 AST 强基线的第四轮比较

日期：2026-10-09（Asia/Shanghai；运行记录使用 UTC）。本轮真实模型比较 **blocked**，按用户“先完成非模型验证”的选择执行，实际模型请求、token、API 费用均为 0。以下数值来自受控程序执行和无模型原因枚举，不是 AI 诊断正确率。

**结论：尚不能证明执行反证优于简单 AST。** 执行能过滤部分静态误归因并发现修复回归，但局部执行也接受了一个错误原因。较强执行闸门消除了本样本的错误接受，同时比 AST 上下文基线少覆盖三个真实原因。没有任何新增正确原因是 AST 上下文基线未覆盖的；真实模型和用户收益仍未测量。

## 3. 五个正式对照

所有组共享相同初始事实和候选池。候选来自任务适用的固定原因目录，14 个程序共枚举 36 条；不人工选择只让执行胜出的断言，不注入预测值，不把枚举改称模型输出。

| 组 | 接受准则 |
| --- | --- |
| B_fact | 结构、代码版本、引用、程序层、合法输入及已有真实失败；不验证解释 |
| B_ast | B_fact 加第三轮简单 AST 干预模式存在 |
| B_ast_context | 再要求变量进入返回值、零初值未被后续顶层赋值覆盖、循环结果进入返回值；不做完整语义分析 |
| B_exec | 实际运行 probe 和固定局部修复；至少一个已观察失败转为通过，已有通过项不得退化 |
| B_exec_guard | B_exec 之后加独立 guard；修复版须全部符合规范 |

B_ast_context 是本轮冻结的较强、透明静态对照，不等于最强可实现静态分析。执行变体仍依赖同样四类有限 AST 干预，没有自动生成任意补丁。基础事实组可以接受模板外原因，但只是放行未核实声明，不能算可靠诊断。

## 5. 最关键的失败与额外价值

**r11：局部通过不能证明根因。** 原函数为 `range(1,n)` 累加后返回 `s+n-1`，相当于正确总和减 1。n=1 原输出 0；错误地给循环多加一轮后输出 1，唯一初始观察和同一个 probe 都通过，B_exec 放行“漏端点”。但循环少算的 n 已经由返回值 +n 补偿，实际缺陷是 -1。

独立 guard n=0/2/4 的规范值为 0/3/10，修复版为 -1/4/13，因此 B_exec_guard 拒绝。该反例推翻“行为预测符合＋局部改善就足以确认因果”的强主张。代码事实是否正确和因果是否正确必须单独判断。

**r03：确实存在静态模式误归因。** 原版 n=4 得到 11，预期 10；“修漏端点”后得到 15，不能改善，执行保持待定。强 AST 因为 s 进入 return 仍接受这个错误原因。这是实际过滤增量，但不证明执行不可被简单代数规则替代；本轮没有实现或测试更强的代数基线。

**r04：更严门槛损失真实原因。** 只修端点能让 n=1 通过，B_exec 接受；guard n=2/5 仍被覆盖累加缺陷影响，guard 版连这个真实端点原因也拒绝。另一个真实覆盖原因因单修无用，两执行组均保持待定。诊断贡献与整个补丁可用性不同。

**r05：执行发现可复核的回归。** 缩短循环后 `[7]` 与 probe `[4]` 修好，但 `[2,3]` 从正确复制退化为 `[2]`。两执行组不接受这份安全修复证据。AST 仍能保留真实索引候选，但不会产生回归记录。这说明执行适合验证“这份修改是否破坏已知行为”，不能因此把真实原因判为不存在。

**r01/r02：简单加强已有价值。** 上下文 AST 不追加执行就剔除了被重置零值和无关 scratch 两项误归因，保留全部七个原本静态支持的真实原因。应先保留这份简单增益。r12 及返回值偏移仍不被当前干预体系支持，多执行没有扩大机制覆盖。

全部原始 probe、干预源码、结果及原因见 verdicts_raw.json（仅本机证据：`experiments/round4/results/B_nonmodel_20261008T155744160724Z_fbfc2d/verdicts_raw.json`；不随 Git 分发）；标签与评分分别见同目录 annotations.json、scored_results.json。

## 6. 标注敏感性与外推限制

r05 的 `compensating_truncation` 标签有争议：长度 2 的截断在原版里恰好补偿额外迭代，未必是当前失败的独立原因，更接近修复耦合风险。本轮没有偷偷改冻结标签，而是单独保存 事后敏感性审阅（仅本机证据：`experiments/round4/results/B_annotation_sensitivity_20261008T160250002039Z_10524e/review.json`；不随 Git 分发）。它是探索性分析，不能代替主评分。

严格排除该标签后真实原因分母为 12：AST_context 7/12，B_exec 5/12，guard 4/12；三者错误接受数仍为 2/1/0。B_fact 变为正确 12、错误 16。核心比较没有翻转，但说明外部独立标注仍必要。

样本由作者刻意构造，原因候选由目录均匀枚举，既不代表学生代码分布，也不代表真实模型会提出的诊断分布。guard 是作者额外设计的测试资源，改善可来自测试质量而非 AI。当前结果不能支持真实 AI 增量、自动认知诊断或普遍因果证明。
