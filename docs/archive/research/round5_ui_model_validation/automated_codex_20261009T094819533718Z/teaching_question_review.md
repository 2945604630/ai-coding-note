多数回答先解释程序事实再追问，学生可能已经接触答案。回忆原始预期的自报、追踪当前代码及真实未暴露的新题资格不能混为一谈。明确两条回答路径是流程结构，不证明能可靠确认误解或提升迁移。

S0 的问题质量仍待同量表人工复核，不用未评审的 0 分让 AI 显得更好。实际学生是否理解、是否依赖完整修复、是否能独立改码、额外步骤是否值得、新题首次表现均没有数据。

优先复核06：两组都识别多加元素及长度2补偿，但均未明确警告单独缩短循环会破坏已通过输入。S1给完整替代方案绕开风险；S2建议逐行核对不同长度，尚不能称自动验证了安全修复。优先复核05的提问是否有必要、01/02/03/07的认知路径能否由固定模板替代，以及04的干预问是否仍有区分力。现有数据只有导师一次回答，没有学生回应或后续适应动作。
