## 限制

三种资格是**当前记录条件**，不是客观独立性真值。系统无法观察未声明的外部帮助；帮助相关性及答案暴露标签依赖可靠输入/人工复核。当前没有统一跨会话学习者和全渠道暴露账本，不能因创建新会话就宣称题目从未见过。题目也未验证为与原题等价的迁移测验。

首次冻结、事件追加与封存哈希能防止应用接口覆盖并检测本次测试中的改写；不是 OS 不可变存储或外部审计认证。有限通过不确认程序整体正确、学生掌握或学习迁移。未知代码仍不执行，受控限制保持不变。
