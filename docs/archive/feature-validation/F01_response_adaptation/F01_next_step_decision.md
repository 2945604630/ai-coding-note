## 3. 错误及不可靠决策

未在本组发现明确程序矛盾、非法输入或完整修复；也没有空输出/模型失败。保留三类教学风险：R03三组澄清都只列部分可能指代；S2_R06复用已有预期值再要求判断，可能诱发复述；S2_R07同样用已曝光规范值询问符合性，实际信息量未知。它们目前是风险，不是已证实误导。S1_R02用“误解”描述有明确错误依据的当前话语，是否被读成持久知识确诊仍需人类复核。初始S0_R03歧义漏记、S0_R06思路披露漏记通过附录校准，初审JSON保留。

## 4. S2是否真正优于S1？

没有成立。7/8情景选同一动作，R06分别选新反例/分层提示，两者均相关；S2没有减少本组可观察的错误归因或完整修复，S1也保留自述/修改结果未确认。S2的额外限定和较长说明不算教学增量。不能用本组零错误证明两组等效，更不能证明S2普遍安全。
