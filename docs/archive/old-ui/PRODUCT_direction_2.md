# AI 编程学习台 V3 · 自主探索

面向在 Windows 浏览器中练习 Python 的初学者。核心任务是看题、编辑代码、回答教学追问、查看可信的运行证据并保存学习过程。沿用本地 web_lab、官方 Codex CLI 及已审核案例。

默认学习模式采用浅色、深绿、低饱和橙色操作强调和系统中文字体。桌面代码区约 65%，辅导区约 35%；题目、代码与执行操作保持在同一工作台，结果、错误回顾与版本修改在编辑器下方切换。窄屏用明确按钮切换代码与辅导，各自保留状态。清楚的操作、可恢复的等待与键盘访问优先，不使用装饰性图片或动画。

研究能力放在独立实验管理入口。学生页避免功能编号、评分量表和原始 JSON；版本指纹折叠在运行来源中。已保存练习代码沿用已验收 Docker 沙箱，旧审核核验单独保留；首次新题仍保存待审。有限测试不证明整体正确，记录资格不证明无外部帮助。

成功条件：默认入口能直接开始或继续真实的两道练习；桌面代码和辅导可协作，窄屏可快速切换；异步调用、刷新恢复、版本对应证据、历史与导出不丢失。未保存、历史查看与运行等待期间不能误发辅导。错误回顾保存真实报错、超时与输出差异，不因后续通过而删除。自动化记录默认隐藏，可明确显示；教学效果不由界面验收认定。
