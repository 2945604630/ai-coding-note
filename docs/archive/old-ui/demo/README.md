# F01～F05 最小 Demo

在项目根目录的 PowerShell 运行：

```powershell
python -X utf8 -m web_lab --port 8006 --data-dir data/aic_demo
```

自动打开 `http://127.0.0.1:8006`。已有同端口服务时打开现有页面；关闭服务用 Ctrl+C。使用独立的 `data/aic_demo/`，不混用原 8000 端口的用户记录。本机已安装依赖且 Codex CLI 已登录；使用官方产品登录，不需要在对话里提供密钥。

1. 保持“F01～F05 · 最小可用 Demo”和“S1 · 真实 Codex AI”，选择审核案例并开始。
2. 首问是明确标记的固定问题。输入自己的回答；每轮只调用一次真实 Codex，同时取得回答理解与下一步动作。最多两次后续回复，允许提前停止。
3. 展开左侧“记录修改后的新代码”。先选择作为修改来源的旧版本，再保存代码。保存本身不执行。
4. 点击顶部“修改核验”，对选中版本核验。仅精确匹配登记哈希的源码能够执行；其他写法即使可能正确，也只保留待审核。结果展示同输入的旧版、新版与参考输出。
5. 点击“新题验收”。如实填写帮助声明，只勾选能确认的记录条件。首次保存即冻结；后续修改单独记录。可补记首次提交前的提示或答案暴露。
6. 刷新或从“历史记录”重新打开原会话。顶部“导出 JSON”包含完整对话、原始模型字节、源码、执行证据、帮助账本和首次提交。CSV 只覆盖原网页的教学表格。

统一 `session_id` 就是现有实验 UUID。代码、调用、核验操作和 F05 账本通过数据库关联及账本内的显式会话事件连接。F01/F02 复用 F02 协议的一次模型调用；F04/F03 复用 `compare()` 与 `verify()`；F05 复用原封存接口。冻结的实验模块没有改写。

S0 明确显示固定规则；S1 连接失败时保留失败和原文，不自动回放或生成替代答案。S1 不是离线回放模式。本次一次真实调用耗时约 129 秒；教学判断仍需你核对。
