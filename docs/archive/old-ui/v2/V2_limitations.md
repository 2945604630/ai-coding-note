# 学习台 V2 · 真实使用限制

- AI 本次等待约 130 秒，沿用既有模型、CLI 传输与 1200 秒超时。没有真正流式输出；刷新可恢复状态，但停掉服务会把未完成调用记录为失败，需要明确重试。结束本题不会取消已提交的模型进程。
- 当前只有两个原审核案例。首次为固定引导，最多两次后续回复；充分理解、等待证据或达到上限时遵守原停止协议。结束后可以保存代码，不能无限继续聊天。
- 只有完全匹配审核登记源码且比较来源也已审核的版本可运行。任意粘贴或 AI 新生成的代码仅保存待审，没有新增审批接口或降低执行限制。通过少量指定输入不能证明整体修复。
- F05 仍使用原记录与资格协议。来源或帮助声明不完整时保留未知；有帮助则标记受影响。首次保存即冻结，未审核代码也不例外。界面不认定知识掌握或学习迁移。
- 输入来源是声明与追加记录，不是身份认证。自动化工具可能隐藏浏览器标记，测试必须显式使用 `?source_type=automated_test`；标记在该浏览器会话内保留。测试浏览器切回手动体验可用 `?source_type=real_user`，这仍只是手动声明。原标签及更正均可在导出中核对。
- 已保存内容在 SQLite，未保存草稿在当前浏览器的 localStorage；清除浏览器数据会丢失草稿，换浏览器不能带走未保存内容。当前没有跨设备同步或多用户认证。正式数据需要自行备份。
- 新题记录建立后，声明范围不自动补为完整。后台保存帮助可用性，不证明学生实际阅读了帮助。实验管理按原创建设定筛选，逐输入来源另行统计，不应把该筛选视为真人人数。
- 本轮验收使用浏览器自动化、一次真实模型回复和确定性失败注入。没有真人实际试用；自由提问是否切题、教学判断可靠性与产品创新性仍待用户体验及人工审查。未增加新的教学机制，也不构成恢复完整学习工作台的依据。
